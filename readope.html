School Open Day

Software Development Event

What is a School Open Day (Software Development)?

It is a showcase event where learners and teachers present projects, skills, and technologies used in software development.

What happens during the event?

1. Student Projects Exhibition

    1. Websites (HTML, CSS, JavaScript) 2. Mobile apps (Android or Flutter apps) 3. Games (simple 2D or 3D games) 4. Databases and systems (student management systems, library systems)

2. Live Coding Demonstrations

    1. Building websites step by step 2. Fixing errors (debugging) 3. Explaining programming logic (loops, functions, conditions)

3. Technology Showcase

    1.Visual Studio Code 2. Git & GitHub 3. Figma (UI design) 4. Python, Java, JavaScript

4. Presentations & Talks

    1. How software is made 2. Career paths in programming 3. Future of AI and technology 4. Why learn coding?

5. Q&A Session

    1. How to start coding 2. What subjects to study 3. Job opportunities in software development

Purpose of the Open Day

    I. Inspire students to join software development II. Show real projects instead of theory only III. Connect students with parents and industry ideas IV. Promote school programs in ICT

Simple Example

A student might show a School Management System built with PHP and MySQL or a portfolio website built using HTML, CSS, and JavaScript.

Why it is important

    I. Builds confidence in students II. Improves communication skills III. Encourages innovation IV. Helps others understand coding in real life
